04 /
Capability discovery & delegation Early implementation

Fabric

Discover a capability and delegate work through a structured contract. Fabric manages asynchronous invocations while reusing session supervision and messaging—without requiring a predefined workflow.

  • Capability catalog
  • Schema-checked results
  • Asynchronous calls
How it differs from Factory +

Factory defines a workflow’s stages and steps. Fabric discovers capabilities and tracks invocations. A capability can be implemented by an agent or a deterministic program; the caller interacts with its input and result contract.
